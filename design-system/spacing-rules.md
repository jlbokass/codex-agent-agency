# Spacing Rules

Use these rules when designing or reviewing pages, components, sections, forms, dashboards, and responsive layouts.

Spacing must create hierarchy, rhythm, clarity, and premium visual quality.

---

# Spacing Goals

Good spacing should:

- guide the user through the page
- separate unrelated content
- group related content
- create visual rhythm
- improve readability
- support responsive design
- avoid template-like layouts

Avoid spacing that feels:

- mechanical
- cramped
- inconsistent
- too empty without purpose
- identical across all sections
- copied from a default framework

---

# Core Principle

Spacing is not decoration.

Spacing must communicate:

- what belongs together
- what is more important
- when a new section begins
- where the user should focus
- how dense or calm the experience should feel

---

# Section Spacing

Major sections need enough vertical separation.

Avoid:

- sections that visually merge together
- identical padding on every section
- cramped transitions
- huge empty areas without content purpose
- mechanical top/bottom spacing

Prefer:

- generous opening sections
- tighter spacing inside related blocks
- stronger separation between major ideas
- varied rhythm between dense and calm sections

A premium layout should feel composed, not stacked.

---

# Component Spacing

Inside components, spacing should clarify structure.

Check spacing between:

- title and subtitle
- subtitle and CTA
- labels and fields
- cards and their content
- images and captions
- icons and text
- error messages and fields
- navigation items

Avoid:

- elements touching visually
- excessive gaps inside small components
- identical padding for all component types
- content floating without alignment

---

# Grouping Rules

Related elements should be visually grouped.

Examples:

- label + input + help text
- title + subtitle
- price + pricing explanation
- CTA + reassurance note
- image + caption
- card title + description

Unrelated elements need stronger separation.

If everything has the same spacing, the hierarchy becomes flat.

---

# Layout Rhythm

A strong page alternates between:

- immersive sections
- dense information sections
- calm reading areas
- conversion moments
- proof/trust blocks
- visual breathing spaces

Avoid:

- all sections having the same height
- all content using the same container width
- all blocks following the same vertical rhythm
- repeated card spacing everywhere

---

# Hero Spacing

Hero spacing should create impact.

Prefer:

- generous vertical breathing room
- strong relationship between title, subtitle, and CTA
- visible CTA without pushing it too low
- balanced spacing between text and visuals

Avoid:

- hero title too close to navigation
- CTA too far from supporting copy
- oversized hero with little content
- mobile hero that pushes CTA below the fold unnecessarily

---

# Forms

Forms require calm and predictable spacing.

Prefer:

- clear spacing between fields
- grouped related fields
- visible labels
- helper/error text close to the field
- submit CTA separated enough from inputs
- reassurance text near the submit action

Avoid:

- cramped field groups
- excessive gaps that break form flow
- unclear relation between error and input
- full-width forms with no internal rhythm

---

# Cards

Cards must not all feel identical.

Avoid:

- same padding in every card
- same height for unrelated content
- too much empty card space
- cramped text inside cards
- grids with equal visual weight everywhere

Prefer:

- stronger spacing for featured cards
- tighter spacing for metadata
- clear grouping of title/body/action
- varied card sizes when hierarchy requires it

---

# Responsive Spacing

Mobile spacing must be intentional.

Avoid:

- simply shrinking desktop spacing
- huge top/bottom padding on mobile
- cramped text blocks
- CTAs too close to other tappable elements
- images and text touching visually
- section rhythm becoming flat after stacking

Prefer:

- reduced but comfortable section padding
- clear separation between stacked blocks
- thumb-friendly spacing around actions
- readable spacing between title and body
- enough breathing room around forms

---

# Density

Choose density based on context.

Use higher density for:

- dashboards
- tables
- admin panels
- forms with many fields
- technical content

Use lower density for:

- landing pages
- premium service pages
- seasonal rentals
- editorial content
- storytelling sections

Do not use landing-page spacing inside dashboards.

Do not use dashboard density on marketing pages.

---

# Spacing Anti-Patterns

Detect:

- identical padding everywhere
- sections visually blending together
- text blocks floating without alignment
- CTA too far from persuasion copy
- cards with excessive internal emptiness
- mobile layouts with awkward gaps
- decorative whitespace with no hierarchy purpose
- too many unrelated items grouped together

---

# Spacing Review Output

When reviewing spacing, return:

- section rhythm assessment
- component spacing issues
- grouping issues
- mobile spacing risks
- density problems
- recommended spacing corrections
- expected UX benefit
