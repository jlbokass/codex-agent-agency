# John Design Language

Use this design language to guide UI/UX, web design, landing pages, dashboards, client websites, and premium interface redesigns.

## Goal

Create interfaces that feel professional, distinctive, modern, and client-ready.

The goal is not to produce generic layouts, but to create strong visual direction, clear UX, and polished execution.

---

## Design Personality

Interfaces should feel:

- premium
- modern
- editorial
- structured
- human
- clear
- elegant
- confident
- conversion-oriented

Avoid designs that feel:

- generic
- template-based
- AI-generated
- visually flat
- overly corporate
- too symmetric
- too crowded
- mechanically spaced
- Bootstrap-default

---

## Core Principles

### 1. Clarity before decoration

Every visual decision must support:

- understanding
- hierarchy
- conversion
- navigation
- trust

Do not add decorative elements unless they reinforce the message or the brand atmosphere.

---

### 2. Strong first impression

The opening section must immediately communicate:

- what this is
- who it is for
- why it matters
- what action the user should take

Avoid weak hero sections with generic centered text and a basic button.

---

### 3. Editorial composition

Prefer layouts inspired by high-quality editorial design:

- strong titles
- controlled asymmetry
- intentional white space
- visual rhythm
- image/text contrast
- structured storytelling

The page should feel composed, not assembled from repeated blocks.

---

### 4. Premium spacing

Spacing must create rhythm.

Avoid:
- identical padding everywhere
- cramped sections
- excessive empty space with no purpose
- mechanical vertical stacking

Prefer:
- generous hero spacing
- tighter grouping for related content
- stronger separation between major sections
- mobile spacing designed intentionally

---

### 5. Clear conversion path

Every page should have:

- one primary action
- optional secondary actions
- clear CTA hierarchy
- repeated CTAs only when useful
- no competition between too many buttons

The user should always understand the next step.

---

## Visual Direction

### Layout

Prefer:

- asymmetrical grids when appropriate
- split layouts
- layered sections
- editorial blocks
- immersive hero sections
- visual anchors
- sections with different rhythm

Avoid:

- repeated card grids
- identical section structures
- default container + row + column feeling
- predictable AI landing page patterns

---

### Typography

Typography should create clear hierarchy.

Prefer:

- strong headings
- readable body text
- controlled line lengths
- contrast between title, subtitle, metadata, and CTA
- confident scale differences

Avoid:

- weak heading sizes
- long text blocks
- centered text everywhere
- generic font pairing without intent

---

### Colors

Use color to create atmosphere and guide attention.

Prefer:

- restrained palettes
- warm neutrals
- deep accents
- high readability
- controlled contrast
- purposeful highlights

Avoid:

- random bright colors
- too many accent colors
- low contrast
- color choices that feel disconnected from the brand

---

### Components

Components should feel designed, not dropped in.

Prefer:

- custom cards when needed
- polished forms
- clear navigation
- refined buttons
- visible focus states
- meaningful hover states
- consistent radius, shadows, and spacing

Avoid:

- default Bootstrap cards
- repeated identical components
- generic badges everywhere
- excessive shadows
- decorative icons without purpose

---

## UX Rules

### User journey

Before designing, identify:

- the user’s main goal
- the business goal
- the primary CTA
- secondary actions
- likely objections
- friction points
- mobile constraints

The design must answer user questions in the right order.

---

### Forms

Forms must be:

- visually calm
- easy to scan
- clearly labeled
- accessible
- reassuring
- not visually overwhelming

For important forms, add contextual trust elements when useful.

Examples:

- short reassurance text
- privacy note
- response time
- payment/security note
- clear error states

---

### Mobile

Mobile must not be an afterthought.

Avoid simply stacking desktop blocks.

Check:

- CTA visibility
- thumb-friendly actions
- readable text
- spacing rhythm
- image cropping
- form usability
- section order

---

## Motion

Motion should be subtle and useful.

Use animation for:

- hierarchy
- feedback
- transitions
- progressive reveal
- perceived polish

Avoid:

- excessive scroll effects
- decorative animation
- motion that hides content
- heavy effects that hurt performance

Respect reduced-motion preferences when relevant.

---

## Anti-Generic Checklist

Before validating a design, ask:

- Does this look like a default AI-generated page?
- Could this be confused with a Bootstrap template?
- Is there a clear design point of view?
- Is there one memorable visual moment?
- Is the CTA hierarchy obvious?
- Is the mobile version intentionally designed?
- Does the design support the client’s positioning?

If the answer is weak, propose a stronger visual direction before implementation.

---

## Expected Output When Designing

When proposing a UI direction, return:

- design intent
- target user
- business goal
- primary CTA
- visual direction
- layout strategy
- typography strategy
- color atmosphere
- responsive strategy
- accessibility considerations
- risks
- files likely to change
