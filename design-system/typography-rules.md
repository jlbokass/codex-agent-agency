# Typography Rules

Use these rules when designing or reviewing pages, layouts, components, forms, dashboards, and content-heavy interfaces.

Typography must guide attention, improve readability, and support the visual identity.

---

# Typography Goals

Good typography should:

- create immediate hierarchy
- make content easy to scan
- support the brand mood
- improve conversion clarity
- improve mobile readability
- make interfaces feel intentional and premium

Avoid typography that feels:

- generic
- flat
- too small
- centered everywhere
- mechanically scaled
- visually weak
- hard to scan

---

# Hierarchy

Every interface must define a clear hierarchy between:

- page title
- section title
- subtitle
- body text
- metadata
- labels
- CTA text
- helper text
- error text

Avoid:

- headings and body text with weak size contrast
- too many heading levels used randomly
- all sections looking equally important
- repeated identical title styles everywhere

Prefer:

- strong page titles
- clear section headings
- concise subtitles
- readable body copy
- smaller but legible metadata
- strong CTA labels

---

# Headings

Headings should be:

- specific
- persuasive when relevant
- scannable
- visually strong
- aligned with the page goal

Avoid vague headings like:

- Welcome
- Our services
- Learn more
- Discover our offers
- Quality service

Prefer headings that express value, context, or intent.

Examples:

- Book a quiet stay near Bordeaux vineyards
- A clear booking flow from dates to payment
- Dance classes designed for real progression
- A premium artisan website without template fatigue

---

# Body Text

Body text should be:

- readable
- concise
- useful
- grouped logically
- visually comfortable

Avoid:

- long full-width paragraphs
- dense text blocks
- repeated marketing fluff
- tiny mobile text
- low contrast body text

Prefer:

- short paragraphs
- controlled line length
- meaningful subheadings
- bullets only when they improve scanning
- helpful microcopy near actions

---

# Line Length

Keep line lengths controlled.

Avoid:

- text spanning the full viewport
- very narrow columns with awkward wrapping
- long legal/content pages without rhythm

Prefer:

- readable content width
- wider layouts only for visual balance
- shorter lines for editorial sections
- clear rhythm on long pages

---

# Alignment

Avoid centering everything.

Use center alignment only when:

- content is very short
- the section is ceremonial or introductory
- the layout benefits from calm symmetry

Prefer left alignment for:

- long copy
- forms
- dashboards
- content pages
- complex information
- mobile readability

---

# Font Scale

Typography scale should feel intentional.

Prefer:

- strong contrast between main title and body
- large expressive hero titles when appropriate
- consistent section title scale
- readable form labels
- clear button text

Avoid:

- tiny headings
- oversized body text
- random scale jumps
- too many font sizes

---

# Font Weight

Use font weight intentionally.

Avoid:

- too many weights
- bold text everywhere
- weak headings with insufficient contrast
- excessive uppercase

Prefer:

- strong but readable headings
- medium weight for key labels
- normal weight for body text
- bold only for emphasis

---

# Mobile Typography

On mobile:

- headings must remain strong but not overwhelming
- body text must be readable
- CTAs must remain clear
- long titles must wrap cleanly
- line height must remain comfortable
- text blocks must not feel cramped

Avoid:

- desktop heading sizes copied directly to mobile
- tiny body text
- compressed line height
- centered long text
- CTA text wrapping awkwardly

---

# Forms

Form typography must be calm and precise.

Use:

- visible labels
- helpful helper text
- clear error messages
- reassuring microcopy
- readable field text
- clear submit CTA

Avoid:

- placeholder-only labels
- tiny error text
- vague button labels
- unclear required-field language

---

# CTA Copy

CTA labels should be specific.

Avoid:

- Submit
- Click here
- Learn more
- Send

Prefer action-oriented labels:

- Check availability
- Request a quote
- Book my stay
- Start the registration
- Send my message
- View class schedule

---

# Typography Review Output

When reviewing typography, return:

- hierarchy assessment
- readability assessment
- mobile typography risks
- weak headings or vague copy
- CTA copy issues
- proposed improvements
