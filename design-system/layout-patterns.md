# Layout Patterns

Use these layout patterns to create more distinctive, premium, editorial, and conversion-oriented interfaces.

The goal is not to copy patterns mechanically, but to avoid generic layouts and create stronger visual composition.

---

# General Layout Principles

Avoid:

- repeated centered sections
- identical card grids
- predictable hero + cards + FAQ structures
- excessive symmetry
- weak opening sections
- same spacing rhythm across all sections

Prefer:

- varied section rhythm
- editorial composition
- controlled asymmetry
- clear visual anchors
- strong CTA placement
- immersive openings
- meaningful section transitions

---

# Pattern 1 — Editorial Hero

Use for:

- premium websites
- seasonal rentals
- artisan websites
- dance association homepages
- landing pages

Structure:

- large expressive title
- short persuasive subtitle
- primary CTA
- secondary trust signal
- large visual element or immersive image
- optional floating detail card

Avoid:

- centered generic heading only
- stock-photo feeling
- equal weight between all elements

Best for:

- first impression
- emotional positioning
- conversion

---

# Pattern 2 — Split Story Section

Use for explaining:

- service value
- product promise
- association identity
- project vision
- rental experience

Structure:

- one strong text column
- one image/visual column
- asymmetrical balance
- short blocks of content
- optional metrics or proof points

Variation:

- text left / media right
- media left / text right
- overlapping image and text card

Avoid:

- long paragraphs
- basic 50/50 layout with no visual tension

---

# Pattern 3 — Immersive Visual Band

Use for:

- atmosphere
- location
- brand emotion
- transition between sections

Structure:

- wide image or visual background
- short overlay text
- optional CTA
- strong contrast
- generous vertical space

Avoid:

- unreadable overlay text
- decorative images without purpose
- heavy visual effects

---

# Pattern 4 — Asymmetrical Feature Grid

Use for:

- benefits
- services
- offers
- property highlights
- event highlights

Structure:

- one large featured item
- two or three smaller supporting items
- varied card sizes
- clear hierarchy
- different visual weight per item

Avoid:

- equal cards everywhere
- too many icons
- repeated card titles with weak content

---

# Pattern 5 — Conversion Section

Use near:

- booking
- contact
- registration
- checkout
- newsletter signup

Structure:

- short persuasive headline
- reassurance text
- primary CTA
- optional secondary CTA
- trust elements
- friction reducers

Examples of trust elements:

- response time
- secure payment
- free quote
- no commitment
- limited places
- verified reviews

Avoid:

- too many CTAs
- vague labels
- weak action copy

---

# Pattern 6 — Process Timeline

Use for:

- explaining steps
- booking process
- service workflow
- onboarding
- course progression

Structure:

- numbered steps
- short labels
- concise explanation
- visual progression
- optional CTA after final step

Avoid:

- excessive detail
- too many steps
- flat list with no hierarchy

---

# Pattern 7 — Proof Section

Use for:

- testimonials
- metrics
- reviews
- trust building
- client reassurance

Structure:

- one strong proof headline
- selected testimonials or metrics
- contextual explanation
- optional link to more proof

Avoid:

- fake testimonials
- too many stats
- unverified claims
- generic review cards

---

# Pattern 8 — Premium Form Layout

Use for:

- contact forms
- booking forms
- quote forms
- registration forms

Structure:

- form on one side
- reassurance/context on the other
- clear field grouping
- visible labels
- helpful error states
- privacy/security note
- clear submit CTA

Avoid:

- full-width bare form without context
- placeholder-only fields
- unclear required fields
- intimidating form density

---

# Pattern 9 — Dashboard Overview

Use for:

- admin panels
- analytics pages
- back offices
- internal tools

Structure:

- summary metrics at top
- primary actions visible
- main content area
- filters/search near data
- clear empty states
- useful table hierarchy

Avoid:

- too many cards
- charts without purpose
- hidden primary actions
- dense data without scanning hierarchy

---

# Pattern 10 — Editorial Content Page

Use for:

- blog posts
- guides
- documentation
- legal pages
- lesson pages

Structure:

- strong title area
- metadata/context
- readable content width
- section headings
- callouts
- related links
- final CTA when relevant

Avoid:

- full-width long text
- weak typographic hierarchy
- no reading rhythm
- excessive decorative elements

---

# Mobile Layout Rules

On mobile:

- prioritize CTA visibility
- reduce decorative complexity
- preserve hierarchy
- avoid huge empty spaces
- avoid tiny text
- avoid placing key information too low
- ensure form usability
- ensure touch targets are large enough

Mobile is not just stacked desktop.

---

# Pattern Selection Rules

Before choosing a pattern, identify:

- page goal
- user intent
- primary CTA
- content density
- emotional tone
- conversion need
- technical constraints

Do not use a pattern just because it looks good.

---

# Expected Output When Using Layout Patterns

When proposing a layout, return:

- selected pattern or combination of patterns
- reason for selection
- section order
- CTA placement
- responsive behavior
- risks
- files likely to change
