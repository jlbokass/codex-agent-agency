# Codex Agent Agency Documentation

`codex-agent-agency` is a reusable development command center for Codex-driven
project work. It collects technical agent profiles, reusable prompts,
repeatable workflows, tool-backed skills, generated project scaffolds, shared
automation scripts, checklists, templates, and design-system guidance.

Use this repository as the source of truth for starting projects, reviewing
changes, generating local project structures, and coordinating repeatable
engineering procedures. It is intentionally human-facing and operational: the
files here help developers and Codex work from the same conventions.

## Main Pages

- [Quick Start](quick-start.md) - the shortest path to the main project
  bootstrap and deployment preparation commands.
- [Folder Roles](folder-roles.md) - what each top-level folder is responsible
  for and how agents, prompts, workflows, templates, skills, scaffolds, and
  scripts differ.
- [Command Reference](command-reference.md) - documented usage for the shared
  bootstrap, Git/GitHub, and Netlify helper scripts.
- [Aliases](aliases.md) - optional shell aliases for frequently used commands.
- [Workflows](workflows/index.md) - repeatable project procedures for
  WordPress, static mockups, Git/GitHub, and Netlify.
- [Troubleshooting](troubleshooting.md) - common local setup, BrowserSync,
  Sass, Local WP, GitHub CLI, and Netlify CLI issues.
- [Roadmap](roadmap.md) - next documentation, workflow, and integration steps.
