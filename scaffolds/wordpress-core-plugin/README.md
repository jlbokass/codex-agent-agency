# WordPress Core Plugin Scaffold

Reusable companion plugin scaffold for `{{PLUGIN_NAME}}`.

This scaffold owns project-specific WordPress structure and business behavior:
Custom Post Types, taxonomies, metadata, admin customizations, and business
logic. It intentionally avoids frontend presentation concerns and theme template
rendering.

## Placeholders

- `{{PLUGIN_NAME}}`
- `{{PLUGIN_SLUG}}`
- `{{TEXT_DOMAIN}}`
- `{{PHP_PREFIX}}`
- `{{AUTHOR_NAME}}`

Do not add client-specific content to this scaffold.
