# Static to WordPress Integration Checklist

Use this checklist before and during static-to-WordPress integration planning.

## Review

- [ ] Static pages reviewed.
- [ ] Template mapping done.
- [ ] Shared layout elements identified.
- [ ] Dynamic sections identified.
- [ ] Content model notes reviewed.

## Theme Structure

- [ ] Header extracted.
- [ ] Footer extracted.
- [ ] Navigation extracted.
- [ ] Template parts created.
- [ ] Static pages mapped to WordPress templates.
- [ ] No business logic added to theme.

## Assets

- [ ] Assets migrated.
- [ ] SCSS strategy documented.
- [ ] JavaScript strategy documented.
- [ ] WP enqueue checked.
- [ ] Mobile navigation checked.

## Dynamic Content

- [ ] Dynamic content identified.
- [ ] CPT/plugin needs documented.
- [ ] Taxonomy needs documented.
- [ ] CPTs and taxonomies kept out of the theme.

## Quality

- [ ] Escaping functions used.
- [ ] Translation functions used for visible strings.
- [ ] Responsive behavior preserved.
- [ ] Accessibility basics reviewed.
- [ ] Integrated pages compared against the validated static mockup.
